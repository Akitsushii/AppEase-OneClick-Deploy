{#- --------------------------------------------------------------------- THE THEME TOGGLE - one macro for the topbar and the Settings rail, so the two cannot drift; only the button chrome differs. Basecoat's theme-switcher, with three deliberate changes: 1. NO onclick="window.basecoat.theme.toggle()": it writes localStorage, which is prohibited here. base.html's controller writes the cookie. 2. NO `dark:` icon swap: those utilities are not compiled, and adding them forces a build-css.bat run. .theme-icon-sun/-moon in app.css do it, scoped under .theme-toggle so they cannot fight Tailwind's .hidden. 3. NO `size-8`: not compiled here, so it would silently do nothing. The icon shows where you are GOING (sun in dark mode), Basecoat's own convention. --------------------------------------------------------------------- -#} {% macro theme_toggle(placement, theme_dark) %} {#- The topbar variant matches its borderless neighbours (a bordered square between circles reads as a mistake); Settings gets Basecoat's outline button. Not `ghost`: its hover paints var(--color-muted), a TEXT grey here, as a background. -#} {%- if placement == 'topbar' -%} {%- set chrome = 'topbar-icon-btn theme-toggle relative inline-flex items-center justify-center rounded-full text-label hover:bg-subtle' -%} {%- else -%} {%- set chrome = 'btn theme-toggle' -%} {%- endif -%} {% endmacro %}
